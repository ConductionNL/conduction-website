## What you build

PetStore: a typed-data app for tracking pets and their owners. One register, two schemas (`pet`, `customer`), a public form that posts to OpenRegister via OpenConnector, and a small Vue panel in Nextcloud that lists pets.

PetStore is a universally recognised example (Swagger's reference API for over a decade), so the schemas and flows here map cleanly to whatever typed-data app you're really building. Swap `pet` for `incident`, `case`, `record`, or `request` and the steps stay the same.

## Steps

1. **Install OpenRegister and OpenConnector** from the Nextcloud app store.
2. **Create the `petstore` register** with two schemas: `pet` (id, name, species, status) and `customer` (id, name, email).
3. **Wire a public form** as an OpenConnector source. For prototyping, an HTML form on a static page is enough.
4. **Map the form fields** to the `pet` schema using OpenConnector's mapping editor.
5. **Build a small Vue panel** in the app dir to list pets, with status filters.
6. **Publish** to your own app store or to apps.conduction.nl.

## When you are done

You have an installable Nextcloud app, a published API (REST + GraphQL auto-generated from the schemas), and a working public form that creates pet records. Total time: about half an hour if Nextcloud is already running.
