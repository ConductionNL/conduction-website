import {Prerequisites, PrerequisiteItem, Outcomes, Outcome, ModulePage} from '@conduction/docusaurus-preset/components';

<ModulePage module="build-an-app-tutorial">

This module builds PetStore, the OpenAPI canonical pet-store app, on the full Conduction stack. You scaffold the app, declare its schemas, plug it into NC Calendar with one config block, layer xWiki care guides, and ship to the Conduction app store. Each part is self-contained. Skip ahead if a chapter looks familiar.

<Outcomes title="What you build">
  <Outcome>A working PetStore Nextcloud app, in your local environment.</Outcome>
  <Outcome>Three OpenRegister schemas (pet, order, category) declared in a single manifest.</Outcome>
  <Outcome>NC Calendar integration without writing a controller or event listener.</Outcome>
  <Outcome>Per-category care guides sourced from xWiki, packaged and published.</Outcome>
</Outcomes>

<Prerequisites title="Before you start">
  <PrerequisiteItem>A Nextcloud on localhost (see the [Run Nextcloud locally](/academy/run-nextcloud-locally) tutorial).</PrerequisiteItem>
  <PrerequisiteItem>OpenRegister installed and running.</PrerequisiteItem>
  <PrerequisiteItem>Node 20 and PHP 8.3 locally, the standard Conduction dev stack.</PrerequisiteItem>
</Prerequisites>

</ModulePage>
