<ModulePage module="openwoo-getting-started">

The Dutch Freedom of Information Act (Woo) requires government bodies to publish documents in eleven information categories. This module is the fastest path from empty register to published Woo files: import the canonical Woo register with all TOOI categories, then link documents to publications via the OpenRegister API.

<Outcomes title="What you learn">
  <Outcome>How to import the canonical Woo register into OpenRegister.</Outcome>
  <Outcome>Which TOOI categories come by default, and when to extend them.</Outcome>
  <Outcome>Four ways to attach files to a Woo publication, with tested API calls.</Outcome>
  <Outcome>Publish, unpublish, and clean up via the API.</Outcome>
</Outcomes>

<Prerequisites title="Before you start">
  <PrerequisiteItem>A Nextcloud with OpenRegister installed (see [Run Nextcloud locally](/academy/run-nextcloud-locally)).</PrerequisiteItem>
  <PrerequisiteItem>A working REST client (curl, HTTPie, Bruno, or Postman).</PrerequisiteItem>
  <PrerequisiteItem>A user with write permissions on the Woo register.</PrerequisiteItem>
</Prerequisites>

</ModulePage>
